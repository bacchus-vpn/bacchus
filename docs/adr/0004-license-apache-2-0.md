# 4. License the open source under Apache-2.0

- Status: superseded by [ADR-0019](0019-relicense-to-agpl-3-0.md) (relicensed to AGPL-3.0, 2026-07-03)
- Date: 2026-07-02

## Context

We want broad adoption and contribution for the client and node, plus protection
from patent claims. The payment repo is proprietary and unaffected.

## Decision

License the public repo under **Apache-2.0** (permissive, with an explicit patent
grant).

## Consequences

- Individuals and organizations can use and contribute under clear terms.
- No copyleft: a fork may go closed. We accept this in exchange for adoption — the
  network effect and the proprietary payment service are the moat, not the code.
